The Database: A cloud-hosted PostgreSQL database on Neon.

The Backend: A lightning-fast Python API using FastAPI.

The AI Brain: A custom Rules Engine combined with an Isolation Forest Machine Learning model (Scikit-learn) to detect anomalies.

The Frontend: A modern React application built with Vite and styled with the brand new Tailwind CSS v4.

The Visualization: An interactive node-graph using React Flow to untangle complex data rings.

The DevOps: Git version control, GitHub hosting, Render backend deployment, and Vercel frontend deployment.
